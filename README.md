# Algorithmic Problem Solving – Level 3

C++ solutions for algorithmic problems and programming exercises .

## Topics Covered

| Topic | Problems |
|---|---:|
| Matrix Operations | 1–20 |
| Fibonacci Series & Recursion | 21–22 |
| Character Handling | 23–29 |
| String Manipulation | 30–44 |
| File Handling & Client Management | 45–51 |

## Implementation Details

- **Language:** C++
- Each problem is implemented in a separate `.cpp` file.
- Solutions are organized by problem number.
- File-based exercises use text files to store and manage client records.

## Problem Categories

### Matrix Operations
- Matrix generation and printing.
- Matrix addition and multiplication.
- Matrix transposition.
- Matrix properties and comparisons.

### Fibonacci Series & Recursion
- Fibonacci sequence generation.
- Recursive Fibonacci implementation.

### Character Handling
- Character case conversion.
- Letter classification.
- Character counting and matching.

### String Manipulation
- String traversal and processing.
- Word counting and extraction.
- String searching and replacement.
- Trimming and reversing strings.
- Punctuation removal.

### File Handling & Client Management
- Converting client records into text lines.
- Saving and loading client data.
- Adding new client records.
- Searching for clients by account number.
- Deleting and updating client records.
